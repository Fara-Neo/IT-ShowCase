# PROJECT OVERVIEW

> **IT Project Showcase & Marketplace**
> Веб-платформа для демонстрации и продажи IT-проектов с заделом под полноценную биржу.

---

## 1. Описание проекта

**IT Project Showcase** — это веб-приложение, которое позволяет разработчикам и командам публично представлять свои IT-проекты в формате профессионального шоурума, а потенциальным клиентам — находить готовые решения и оформлять заявки на их приобретение или доработку.

### Какую проблему решает

Большинство разработчиков не имеют единой, профессионально оформленной площадки для демонстрации своих проектов потенциальным заказчикам. Существующие решения (GitHub, Behance, личные сайты) либо технически сложны для восприятия нетехническими клиентами, либо не предоставляют механизмов для получения заявок и монетизации. Фриланс-биржи, в свою очередь, ориентированы на заказ услуг, а не на продажу готовых продуктов.

**Платформа закрывает этот разрыв**: разработчик публикует проект с описанием, скриншотами и ценой — клиент оставляет заявку в два клика.

## 2. Цели проекта

### Краткосрочные (0–3 месяца)
- Запуск публичного портфолио-шоурума с каталогом проектов.
- Реализация формы заявки с уведомлением продавца и клиента по email.
- Административная панель для управления проектами и заявками.
- Полная адаптивность и поддержка тёмной/светлой темы.
- Базовая система ролей: `guest`, `user`, `seller`, `admin`.

### Долгосрочные (3–12 месяцев)
- Переход от шоурума к полноценной бирже IT-проектов.
- Встроенная онлайн-оплата (Stripe / ЮКасса / иной провайдер).
- Система рейтингов, отзывов и верификации продавцов.
- Маркетплейс цифровых товаров: исходный код, лицензии, SaaS-подписки.
- Встроенный мессенджер между покупателем и продавцом.
- API для интеграции с внешними платформами.

## 3. Целевая аудитория

| Сегмент | Описание | Основная ценность |
|---|---|---|
| **Разработчики / Фрилансеры** | Создают проекты и хотят их монетизировать | Площадка для продажи и демонстрации работ |
| **Небольшие IT-команды** | Продают готовые решения малому бизнесу | Удобный инструмент для витрины продуктов |
| **Малый и средний бизнес** | Ищут готовые IT-решения под свои задачи | Быстрое нахождение и приобретение решений |
| **Технические директора / CTO** | Оценивают проекты для интеграции | Подробная техническая документация проектов |
| **Инвесторы / Покупатели стартапов** | Ищут перспективные продукты | Агрегация проектов в одном месте |

## 4. Ключевые метрики успеха

### Продуктовые метрики
- **MAU (Monthly Active Users)** — целевое значение: 500+ через 3 месяца, 5 000+ через год.
- **Количество опубликованных проектов** — 50+ в первые 3 месяца.
- **Конверсия просмотр → заявка** — целевое значение: ≥ 5%.
- **Время до первой заявки для нового продавца** — менее 24 часов после регистрации.

### Технические метрики
- **LCP (Largest Contentful Paint)** — менее 2,5 с.
- **FID / INP** — менее 100 мс.
- **Uptime** — 99,5%+.
- **Время ответа API** — медиана менее 200 мс.

### Бизнес-метрики (долгосрочно)
- **GMV (Gross Merchandise Value)** — объём транзакций через платформу.
- **Take Rate** — комиссия платформы при переходе на модель биржи (целевое: 10–15%).

## 5. Дизайн и стиль

### Цветовая палитра

Проект использует CSS-переменные через `next-themes` с двумя схемами:

| Роль | Light Mode | Dark Mode |
|---|---|---|
| Background | `#ffffff` | `#0a0a0a` |
| Surface / Card | `#f4f4f5` | `#141414` |
| Border | `#e4e4e7` | `#27272a` |
| Primary (акцент) | `#6366f1` (Indigo-500) | `#818cf8` (Indigo-400) |
| Primary Hover | `#4f46e5` | `#6366f1` |
| Text Primary | `#09090b` | `#fafafa` |
| Text Secondary | `#71717a` | `#a1a1aa` |
| Destructive | `#ef4444` | `#f87171` |
| Success | `#22c55e` | `#4ade80` |

### Типографика
- **Основной шрифт:** Inter (Google Fonts) — современный, читаемый, нейтральный.
- **Моноширинный (для кода):** JetBrains Mono.
- **Размерная сетка:** базируется на Tailwind-шкале (`text-sm`, `text-base`, `text-lg`, `text-xl`, `text-2xl`, `text-4xl`).

### Анимации
- Переходы между страницами: `framer-motion` `AnimatePresence` + `motion.div` с `opacity` и `translateY`.
- Hover-эффекты на карточках проектов: `scale-[1.02]`, `shadow-lg`, плавный переход `transition-all duration-200`.
- Скелетон-лоадеры при загрузке данных (компонент `Skeleton` из `shadcn/ui`).
- Toast-уведомления (`react-hot-toast`) — появляются снизу-справа с анимацией slide-up.
- Анимированный счётчик на hero-секции (количество проектов, заявок, пользователей).

### Адаптивность
- Mobile-first подход через Tailwind breakpoints: `sm` (640px), `md` (768px), `lg` (1024px), `xl` (1280px), `2xl` (1536px).
- На мобильных устройствах: сворачиваемое навигационное меню (бургер), одноколоночная сетка карточек, адаптированные формы.
- На планшетах: двухколоночная сетка.
- На десктопе: трёхколоночная сетка в каталоге, фиксированный сайдбар в админ-панели.
- Все интерактивные элементы имеют зону касания не менее 44×44px (WCAG 2.1 AA).

### Компонентная библиотека
Используется `shadcn/ui` как основа — компоненты адаптированы под фирменный стиль через `tailwind.config.ts` и CSS-переменные в `globals.css`. Кастомизация минимальна, что ускоряет разработку и обеспечивает консистентность.
